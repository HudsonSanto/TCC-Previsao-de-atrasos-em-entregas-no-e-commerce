#  Previsão de Atrasos em Entregas no E-commerce  
### Machine Learning e Visualização com Power BI

##  Descrição do Projeto
Este repositório contém o projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do MBA em Data Science e Analytics, cujo objetivo é **prever atrasos em entregas de pedidos de e-commerce utilizando técnicas de aprendizado de máquina**, bem como **apresentar os resultados por meio de dashboards interativos no Power BI**.

O estudo utiliza dados reais do conjunto **Brazilian E-commerce Public Dataset (Olist)**, amplamente utilizado em pesquisas acadêmicas, permitindo a análise de fatores logísticos, operacionais e comerciais que impactam o prazo de entrega.

---

## Objetivo
Desenvolver um modelo preditivo capaz de estimar a probabilidade de atraso na entrega de pedidos, permitindo:

- Identificação de pedidos com maior risco de atraso  
- Análise dos fatores que influenciam o desempenho logístico  
- Apoio à tomada de decisão por meio de visualizações interativas  
- Comparação de diferentes algoritmos de Machine Learning

## Etapas do Projeto

1. **Pré-processamento dos dados**
   - Limpeza e tratamento de dados
   - Criação de variáveis derivadas (lead time, atraso, etc.)

2. **Análise Exploratória**
   - Distribuições
   - Identificação de padrões

3. **Modelagem Preditiva**
   - Treinamento de modelos supervisionados
   - Comparação de desempenho

4. **Interpretação dos Resultados**
   - Importância das variáveis
   - Identificação de fatores críticos de atraso

5. **Visualização**
   - Construção de dashboard no Power BI
   - Apoio à tomada de decisão logística
